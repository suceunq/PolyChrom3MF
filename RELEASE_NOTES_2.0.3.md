# PolyChrom 3MF 2.0.3

## Correctifs

- Correction de l’erreur `Fragment 3MF absent pendant l’export`.
- Recherche tolérante à la casse et à l’encodage des chemins de fragments 3MF.
- Reconstruction automatique d’un package 3MF autonome lorsqu’un fragment de production manque.
- Validation systématique du fichier reconstruit avant sa livraison.
- Le bouton **Ouvrir dans mon slicer** prépare désormais un 3MF temporaire contenant les couleurs et motifs actuellement visibles.
- Validation avec Snapmaker Orca sur le modèle réel `moai+haaland.3mf`.
