# Installation

Téléchargez l'installateur depuis la [dernière Release GitHub](https://github.com/suceunq/PolyChrom3MF/releases/latest), puis lancez `PolyChrom3MF_Setup_x64.exe`.

Lancez `PolyChrom3MF_Setup_x64.exe`, choisissez le dossier puis terminez l’assistant. La version est autonome et fonctionne sous Windows 10/11 x64 sans SDK .NET.
