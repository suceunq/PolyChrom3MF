# PolyChrom 3MF 2.0.9

- Les motifs PNG/JPG répétés couvrent la pièce avec un raccord miroir continu afin d’éviter les lignes de démarcation.
- La projection triplanaire mélange désormais les trois directions au lieu de changer brutalement d’axe.
- L’image est échantillonnée avec interpolation bilinéaire pour un résultat plus régulier.
- « Gérer mes couleurs de filament » permet de choisir de 2 à 32 couleurs et de toutes les configurer dans une seule fenêtre.
- Chaque couleur peut être associée à du PLA ou du PETG.
- L’export 3MF transmet les profils `Generic PLA` et `Generic PETG` pour leur présélection dans Snapmaker Orca, OrcaSlicer, Bambu Studio et les slicers compatibles.
