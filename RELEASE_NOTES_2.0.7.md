# PolyChrom 3MF 2.0.7

- Désactivation individuelle d'une couleur depuis le clic droit.
- Redistribution automatique des zones vers la couleur restante la plus proche.
- La couleur désactivée est réellement retirée de l'export 3MF.
- Deux couleurs actives minimum afin de conserver un projet multicolore valide.
- L'action peut être annulée avec la commande Annuler.
