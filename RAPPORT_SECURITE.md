# Rapport de sécurité

Audit de code effectué : chemins ZIP traversants et absolus refusés, taille et nombre d’entrées limités, DTD et résolveurs XML externes désactivés, aucun appel réseau, aucune télémétrie et aucun secret stocké. Risque résiduel : le parseur 3MF simplifié ne couvre pas encore toutes les extensions propriétaires.
